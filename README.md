# TKBplorer

macOS用のタブ型ファイルマネージャーです。タブ、2ペイン（左右・上下）、リスト・サムネイル・カラムの3つの表示形式、Quick Look、詳細検索、バッチ名前変更、Finder互換タグ、ネットワーク共有やiCloud Drive・OneDriveへの対応など、日々のファイル整理をFinderに戻らずに済ませることを目指しています。

- **ダウンロード**: [Releases](https://github.com/TKBlabs/TKBplorer/releases)（最新版のDMG）
- **製品ページ**: https://apps.tkbtk.com/TKBplorer/
- **動作環境**: macOS 26.5以降、Apple Silicon（Intel Macには対応していません）
- **ライセンス**: フリーウェア（個人・商用を問わず無料）

## インストール

1. [Releases](https://github.com/TKBlabs/TKBplorer/releases)から最新版の `TKBplorer_<バージョン>.dmg` をダウンロードします。
2. DMGを開き、`TKBplorer.app` を「アプリケーション」フォルダへドラッグします。
3. 「アプリケーション」フォルダから起動します。

アプリとDMGはどちらもAppleの公証（Notarization）を受けています。初回起動時に「インターネットからダウンロードされたアプリケーションです」と確認が出たら「開く」を押してください。

> [!IMPORTANT]
> DMGの中やダウンロードフォルダから直接起動すると、自動アップデートがうまく動かないことがあります。「アプリケーション」フォルダ以外から起動した場合は、TKBplorerが移動を勧めます。「移動して起動し直す」を選ぶと、移した先で起動し直します。

## アップデート

自動アップデート（Sparkle）に対応しています。

- 24時間ごとに新しい版を確認します（設定の「更新」タブでオン・オフできます）。
- メニュー「TKBplorer」→「アップデートを確認...」で、すぐに確認することもできます。
- 更新ダイアログで「今後は自動でダウンロードしてインストールする」をオンにすると、以後は確認なしで裏でダウンロードし、TKBplorerの終了時に新しい版へ入れ替えます。

各版の変更点は[Releases](https://github.com/TKBlabs/TKBplorer/releases)に載っています。

## 主な機能

### 画面とナビゲーション

- タブ（並べ替え、複製、ピン留め、閉じたタブを再度開く）
- 左右・上下の2ペイン表示。ペインごとにタブ・履歴・場所・表示形式・並び順を持ち、分割の比率も保存します。分割線をダブルクリックすると、サイドバーを除いて左右（上下）の幅を半分ずつに揃えます
- リスト・サムネイル・カラム（Finder風）の3つの表示形式。フォルダごとに表示形式を記憶します
- 戻る・進む・親フォルダへ・パスを入力して移動
- サイドバー: お気に入り、よく使う項目、外部ドライブ・SDカード、ネットワーク共有、iCloud Drive・OneDrive・Google Drive、ゴミ箱

### 検索

- ファイル名の検索と、サブフォルダを含む検索
- 変更日・種類・サイズ・タグでの詳細検索
- 検索の保存、検索履歴・移動履歴からの再利用

### ファイル操作

- 新規フォルダ、名前の変更（一覧上でそのまま編集）、コピー・カット・ペースト、移動してペースト、複製、ゴミ箱に入れる
- ドラッグ＆ドロップ。右ボタンでドラッグすると、ドロップ時にコピーか移動かを選べます
- サイドバーの「よく使う項目」やお気に入りのフォルダへのドロップで移動（Optionキーを押しながらでコピー）。ゴミ箱へのドロップでゴミ箱へ移します
- 写真アプリからのドロップで、元の写真・動画を保存します。ファイル名は「オリジナルのファイル名（IMG_1234）」か「撮影日（YYYYMMDD HHMMSS）」から選べます
- コピー・移動の進捗表示（転送速度・残り）、一時停止・キャンセル、キュー、履歴
- 同名の項目があるときの処理（毎回確認／両方を残す／置き換える／スキップ、「すべてに適用」）
- 取り消し・やり直し
- バッチ名前変更（プレビュー、連番、検索と置換、名前の重複チェック）
- Finder互換のタグ・カラーラベルの表示と編集
- ZIPの圧縮・展開
- 情報を見る（Finderの情報ウィンドウか、TKBplorer内の表示かを選べます）
- Quick Lookでのプレビュー。表示したまま矢印キーで次のファイルへ移ったり、ゴミ箱に入れて次のファイルへ進んだりできます

### 外部ドライブとネットワーク共有

- 外部ドライブ・SDカードの取り出し（サイドバーの取り出しボタン、または右クリック）
- SMBなどのネットワーク共有への接続・切断・再接続。サイドバーの未接続の共有には「接続」ボタンが出ます
- 共有が切断されても、開いていたタブは元のフォルダのまま待ち、再接続されると同じフォルダを表示し直します
- サーバーから15秒応答がないときは「サーバーから応答がありません」と表示し、「再試行」で読み直せます。スリープから復帰したあとは、共有フォルダを開いているタブを自動で読み直します
- 共有が未接続のままでも、そのフォルダを開いていたワークスペースへ切り替えられます。見つからないタブも残し、接続後に読み直せます

### OneDrive

- OneDriveのフォルダーの色（16色）を表示します。Web版やWindows版で設定した色が反映されます
- 右クリックからフォルダーの色を変更できます（設定でTKBplorerからOneDriveへのサインインを有効にした場合。共有ライブラリなど一部のフォルダーは変更できません）
- 共有しているフォルダーに人型のマークを、「Shortcuts」フォルダーにビルのマークを表示します
- 右クリックの「オンラインで開く」で、そのアカウントの「マイファイル」をブラウザで開きます

### 外部アプリとの連携

- Finderで表示、ターミナルで開く（使うアプリは設定で選べます）
- このアプリケーションで開く（対応するアプリの一覧を表示）

### カスタマイズ

- ツールバー項目とリストの列の表示・非表示・並び順
- 表示密度（コンパクト／標準／ゆったり）、文字サイズ（12〜32pt）、表示倍率
- キーボードショートカットの割り当て（標準／代替／なし）
- ワークスペース（ペイン構成とタブの組み合わせ）の保存・切り替え・複製・削除
- 前回終了時のタブとウィンドウの状態を復元

## 設定

設定は6つのタブに分かれています。

| タブ | 内容 |
| --- | --- |
| 一般 | 前回終了時のタブを復元、新規タブの表示形式、「情報を見る」の表示先、共有ライブラリ内のOfficeファイルの開き方、OneDriveのフォルダーの色とサインイン、ターミナルで開くときに使うアプリ、設定やデータのリセット |
| 表示 | 隠しファイル・.DS_Storeの表示、表示密度、文字サイズ、既定の並び替えと順序、アイコンサイズ・表示形式・列幅・リストの列設定のリセット、サイドバーの「よく使う項目」 |
| カスタマイズ | ツールバー項目とリストの列の表示・非表示と並び順（「名前」列は外したり動かしたりできません） |
| ショートカット | 各操作のキー割り当て |
| ファイル操作 | 同名の項目があるときの処理、写真アプリからドロップしたときのファイル名、時間のかかるコピー・移動で進行状況ウィンドウを表示 |
| 更新 | 自動で更新を確認するかどうか、最後に確認した日時、「今すぐ確認」、現在のバージョン |

ワークスペースの一覧・並べ替え・作成・複製・削除・切り替えは、別ウィンドウの「ワークスペースの設定」で行います。

## 困ったときは

- **ゴミ箱などの中身が見えない**: 一部のフォルダを表示するには「フルディスクアクセス」の許可が必要です。システム設定 →「プライバシーとセキュリティ」→「フルディスクアクセス」でTKBplorerをオンにしてください。
- **OneDriveのファイルをゴミ箱に入れるときに確認が出る**: macOSの許可の都合でFinderにゴミ箱への移動を頼むことがあり、初回だけ「TKBplorerがFinderを制御しようとしています」と表示されることがあります。
- **自動アップデートが失敗する**: TKBplorerが「アプリケーション」フォルダにあるか確認してください。

不具合を報告していただくときは、次のコマンドで取得したログを添えていただけると調査が早くなります。

```sh
log show --last 1h --predicate 'subsystem == "com.tkbtk.TKBplorer"' --style compact
```

## プライバシー

ファイルの内容・検索語・認証情報を外部へ送ることはありません。クラッシュレポートはmacOS標準の診断機能に任せ、開発者へ自動で送ることはありません。通信するのは、アップデートの確認（apps.tkbtk.com とGitHub）と、OneDriveへのサインインを有効にしてフォルダーの色を変えるときのMicrosoftのサービスだけです。
