TKBplorer — ファイル

概要

// overview

TKBplorerは、macOSの日常的なファイル整理を一つの画面で進めるためのファイル管理アプリです。 タブと左右・上下の2ペインを使い、場所を行き来しながらコピー、移動、検索、プレビューを行えます。

ファイル操作の進捗とキャンセル、Finder互換タグ、バッチ名前変更、ZIP、ネットワーク共有、 iCloud Drive、ワークスペース保存まで、Finderへ戻らず完結できる機能をまとめています。

主な機能

// features
⧉

タブと複数ペイン

左右・上下2ペイン、ペインごとのタブと履歴、再起動後の作業状態復元に対応しています。

⌨

安全なファイル操作

コピー、移動、削除の進捗、キャンセル、競合解決、キューと操作履歴を確認できます。

✎

整理と詳細検索

バッチ名前変更、Finder互換タグ、保存済み検索、更新日・種類・サイズによる詳細検索を利用できます。

▣

常設プレビュー

選択したファイルを画面内で確認しながら、一覧や別ペインでの操作を続けられます。

◐

外部・ネットワーク・iCloud

外部ドライブ、SMBなどのネットワーク共有、iCloud Driveを同じ操作感で扱えます。

♫

表示とワークスペース

ツールバー、表示密度、列、ショートカットを調整し、ペインとタブの構成を保存できます。

# TKBplorer

タブと複数ペインで、コピー、整理、検索、プレビューまでを一つの画面で進めるmacOS用ファイル管理アプリです。

## インストール

  • DMGを開き、TKBplorer.app を「アプリケーション」フォルダへドラッグします
  • Appleの公証（Notarization）済みのため、そのままダブルクリックで起動できます
  • v1.0.29以前から入れ替える場合は、フルディスクアクセスなどの許可を付け直してください

## アップデート

  • 24時間ごとに自動で更新を確認し、新しい版があればお知らせします
  • メニュー「TKBplorer」→「アップデートを確認...」から手動でも確認できます
  • 自動確認の有無は 設定 → 更新 で切り替えられます
  • アップデート時もGatekeeperの追加操作は不要です

## 動作環境

  • macOS Tahoe 26.5以降
  • Apple Silicon 搭載Mac（Intel Mac非対応）

## 主な機能

  • タブ、左右・上下2ペイン、セッション復元
  • ファイル操作の進捗、キャンセル、競合解決、履歴
  • Finder互換タグ、バッチ名前変更、ZIP、詳細検索、常設プレビュー
  • 外部ドライブ、ネットワーク共有、iCloud Drive

## ライセンス
